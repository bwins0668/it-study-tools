# Round 64.0 用户使用指南报告

## 目标
创建 `docs/USER_GUIDE.md`，面向普通用户，说明学习、同步、导出、Dashboard、错题本、打字练习。

## 用户使用指南大纲

### 1. 快速开始
- 打开应用（Web：访问 URL / Windows：解压 Portable ZIP）
- 选择科目（SQL / Java / Python / IT Passport / SG）
- 开始学习第一课

### 2. 学习功能
- **课程学习**：阅读课程内容、查看代码示例
- **练习题**：测试知识掌握情况
- **实操**：编写代码并查看结果（Java/Python）
- **SQL Playground**：编写 SQL 查询并查看结果表格

### 3. 学习统计（Dashboard）
- 查看学习进度（完成课程数、测验分数）
- 设置学习目标
- 查看学习历史图表

### 4. 错题本
- 查看答错的题目
- 重新练习错题
- 标记已掌握的错题

### 5. 打字练习
- 日语打字练习（提高输入速度）
- 编程打字练习（提高代码输入速度）
- 查看打字历史记录

### 6. 术语库（Glossary）
- 搜索 IT 术语（中日英韩）
- 收藏常用术语
- 查看术语别名和相关术语

### 7. 数据管理
- **导出数据**：下载学习数据备份（JSON）
- **导入预览**：预览备份文件内容（只读）
- **同步数据**：登录后同步学习数据到云端

### 8. 设置
- 切换语言（中文 / 日文 / 英文 / 韩文）
- 切换主题（亮色 / 暗色）
- 清除本地数据

### 9. 常见问题（FAQ）
- 如何恢复学习进度？
- 导出数据包含什么？
- 同步安全吗？
- 如何报告问题？

### 10. 联系支持
- GitHub Issues 链接
- 邮件支持（如果有）
