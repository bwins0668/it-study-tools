# Round 65.0 账号与同步帮助优化报告

## 目标
在 UI 中更清楚解释登录、同步、设备、隐私，不改认证逻辑。

## 优化方案

### 1. 同步帮助文档
创建 `docs/SYNC_HELP.md`：
- 什么是同步？
- 同步哪些数据？
- 同步安全吗？
- 如何同步？
- 同步冲突怎么办？

### 2. UI 帮助提示
在同步相关 UI 添加帮助提示：
- 登录按钮：添加 `title="同步学习数据到云端"`
- 同步状态：显示"已同步 X 分钟前"
- 同步错误：显示友好错误消息

### 3. 隐私说明
在设置页面添加隐私说明：
- 我们收集什么数据？（只收集学习进度）
- 我们如何使用数据？（只用于同步）
- 我们如何保护数据？（加密传输、安全存储）

### 4. 多设备使用指南
- 在一台设备登录
- 学习数据自动同步
- 在另一台设备登录同一账号
- 数据自动下载到新设备

### 5. 代码修改范围
- **修改**：`index.html`（添加帮助提示）、`assets/js/sync-engine.js`（改进错误消息）
- **新增**：`docs/SYNC_HELP.md`
- **i18n**：添加帮助提示翻译（4 语言）

## 实施优先级
1. 高：同步帮助文档、UI 帮助提示
2. 中：隐私说明
3. 低：多设备使用指南（视频？）

## Round 65.0 结论
PASS → 可实施，优化账号与同步帮助 UI。
